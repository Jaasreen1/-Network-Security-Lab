# Methodology and ethics

This repository contains a working local parser for exported network metadata, not an active scanner or intrusion detector.

1. Collect exports only from systems you own or have explicit permission to test.
2. Export Nmap results as XML and Wireshark packet lists as CSV with Source, Destination and Protocol columns.
3. Remove credentials, identifying details and sensitive network information before publication.
4. Run the analyzer and review the report.
5. Separate observations from hypotheses and independently verified findings.

**Demo data are synthetic.** Open ports are not proof of vulnerabilities. Traffic statistics alone do not identify attacks.
